# JDG Гид — концепция бота и Mini App

**Дата:** 2026-07-21 · **Статус:** концепция, не начато
**Продукт:** Telegram-бот + Mini App «Путеводитель по JDG (ИП) в Польше»
**Экосистема-источник:** гайд https://sobolevbel.github.io/jdg/ + чат-сообщество https://t.me/JDG_PBH (+ существующий @chatlyfy_bot — поиск по чату)

---

## 1. Идея одним абзацем

Сообщество JDG_PBH уже накопило два актива: структурированный гайд (MkDocs, 12 разделов: регистрация, ZUS, налоги, декларации, inFakt/wFirma и т.д.) и живой чат с тысячами разобранных вопросов. Chatlyfy ищет по сырому чату, но не структурирует. Наш продукт — Mini App в дизайн-системе ISSA, который превращает это в **персонального ассистента предпринимателя**: структурированная база знаний + калькуляторы + календарь дедлайнов + AI-ответы (RAG по гайду и FAQ сообщества) + постоянный мониторинг официальных источников (biznes.gov.pl, podatki.gov.pl, zus.pl) с персональными пушами «это изменение касается тебя».

Ключевое отличие от гайда-сайта: сайт отвечает «как устроено», бот отвечает «что делать **тебе** и **когда**».

## 4. Модули Mini App

### 4.1 Гайд (ядро, Этап 1)
- Разделы = таксономия сайта, offline-first (content_data.js), поиск по всем разделам.
- **Интерактивные чек-листы** с прогрессом (паттерн konspekt/progress ISSA): «Открываю JDG» (PESEL → Profil Zaufany → CEIDG → ZUS → банк), «Первый месяц», «Ежемесячная рутина», «Закрытие JDG». Галочки хранятся в профиле → двигают календарь.
- Словарь терминов PL→RU (паттерн glossary ISSA).

### 4.2 Калькуляторы (Этап 1, сильнейший магнит)
- **ZUS-калькулятор**: этап (Ulga na Start 6 мес → Preferencyjne 24 мес → Mały ZUS+ / Duży) + dobrowolne chorobowe → składki в zł/мес. Таблицы ставок версионируются по годам (2026, 2027…).
- **Сравнение форм налогообложения**: skala 12/32% vs liniowy 19% vs ryczałt (ставка по PKD) при заданном доходе/расходах, с учётом składka zdrowotna по каждой форме → «твоя эффективная ставка» и рекомендация.
- **Składka zdrowotna** отдельно (самый частый вопрос чата).
- **VAT-лимит-трекер**: ввёл обороты → сколько осталось до 200 000 zł, прогноз даты превышения.
- Все ставки — в одном `rates_2026.json` с версионированием (паттерн LOCATION_SCORE: модель версионируется, изменения логируются).

### 4.3 Календарь предпринимателя (Этап 1–2)
- Генерируется из профиля: ZUS DRA + składki до 20-го, VAT/JPK_V7M до 25-го (если VAT-owiec), авансы PIT, годовой PIT до 30.04, **переходы ulg** (конец Ulga na Start, конец Preferencyjnych — считаем от даты регистрации, юзеры это massово пропускают → это killer-фича).
- Пуши: за 5 дней, за 1 день; тихие часы (буфер → утренний дайджест, паттерн KwadratPL).

### 4.4 Профиль (фундамент персонализации)
- Дата регистрации JDG, форма налогообложения, VAT да/нет, PKD/сфера, город. Хранится на сервере (нужен для пушей), RODO: экспорт/удаление одной кнопкой (паттерн KwadratPL `/api/subs` DELETE).

### 4.5 AI-ассистент (Этап 3)
- RAG: вопрос → поиск по (гайд + FAQ сообщества + свежие новости) → Claude Haiku с контекстом → ответ с **ссылками на разделы гайда** и датой актуальности источника.
- Учитывает профиль: «у тебя ryczałt и Ulga na Start, значит…».
- Обвязка целиком из KwadratPL: кэш сутки, лимит N/день, /stats для админа, бюджет-блокер.
- Дисклеймер везде: «не юридическая/налоговая консультация» + кнопка «спросить в чате JDG_PBH» (симбиоз с сообществом, не конкуренция) + позже партнёрская кнопка «спросить бухгалтера» (Legal Tax Level — уже партнёр гайда).

### 4.6 Мониторинг «Что нового» (Этап 2, уникальная ценность)
- Пайплайн: скрейпер (см. §2.3) → новые записи → Claude Haiku: {касается ли JDG, темы: ZUS|VAT|PIT|ryczałt|KSeF|легализация, важность 1–3, выжимка RU 2–3 предложения, кого касается: формы налогообложения/VAT-статус} → лента в Mini App + пуш тем, чей профиль матчится.
- Пуш вида: «⚠️ ZUS: с 01.2027 меняются składki preferencyjne — касается тебя (ты на этапе preferencyjne до 03.2027). Подробнее →».
- KSeF-обратный отсчёт — отдельный виджет (обязателен с 2026, горячая тема).
- Дайджест «Изменения месяца» — авто-пост, который админы могут репостить в чат JDG_PBH (виральность + польза сообществу).

### 4.7 FAQ сообщества (Этап 3–4)
- Топ-вопросы чата, кластеризованные и вычитанные, со ссылками «обсуждение в чате» (t.me/JDG_PBH/123456). Обновление раз в месяц полуавтоматом.

### 4.75 Интеграция inFakt (Этап 2.5) — реальные данные вместо ручного ввода
Проверено 2026-07-21: inFakt API v3 (`https://api.infakt.pl/api/v3/`, заголовок `X-inFakt-ApiKey`,
ключ юзер генерирует сам: Ustawienia → Inne opcje → API, https://app.infakt.pl/app/ustawienia/inne_opcje/api).
Лимиты: 300 GET/мин. Доступны не только фактуры, но и учёт:
- `invoices.json` (+corrective/advance/final/oss), `documents/costs.json`, `books.json` (KPiR)
- **`income_taxes.json` — рассчитанные налоги к оплате**, **`insurance_fees.json` — взносы ZUS**
- `saf_v7_files.json` (JPK V7), KSeF-интеграция (сабмит и XML)

Что это даёт боту:
1. **VAT-лимит-трекер сам заполняется** суммой продаж YTD из invoices.
2. **Дедлайны с реальными суммами**: «до 20-го — ZUS 919,21 zł + ryczałt 1 840 zł» (income_taxes + insurance_fees, там же статус оплачено/нет).
3. **Сравнение форм на реальных цифрах** выручки/расходов за 12 мес, а не на прикидках.
4. **Месячная рутина-чеклист автоотмечается**: фактуры выставлены, JPK сгенерирован.
5. AI-ассистент отвечает с контекстом реальной ситуации («твой доход в этом году X…»).

Реализация: юзер вставляет ключ в профиле Mini App → шифруем (Fernet, ключ в .env) → храним в SQLite → серверный поллер раз в сутки + on-demand. Scope read-only достаточен. Аналогично позже wFirma (у неё тоже есть API).

### 4.8 Монетизация и виральность
- Stars-донат внутри Mini App (createInvoiceLink + openInvoice, эталон KwadratPL — правило [[pattern-stars-miniapp]]).
- Шейринг результата калькулятора в чат («Мои składki на 2027: …» — карточкой).
- Партнёрские реф-ссылки inFakt/wFirma (в гайде уже есть их разделы), Legal Tax Level.

## 7. Риски

- **Актуальность = всё.** Ставки ZUS/налогов меняются ежегодно, ошибка в калькуляторе = потеря доверия. Митигируется: rates.json версионирован, мониторинг источников сам сигналит о изменениях ставок, на каждом экране «данные актуальны на {дата}».
- **Не юрконсультация**: дисклеймеры + AI отвечает только по базе знаний, отказывается от edge-кейсов в пользу «спроси в чате/у бухгалтера».
- **Контент чужой**: без согласия автора гайда парсить его нельзя — либо договориться, либо писать свою базу (дольше). Вопрос №2 — блокер Этапа 1 в полном объёме; калькуляторы и календарь от него не зависят.
