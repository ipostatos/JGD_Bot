# Как вносить изменения

## Ошибка в цифрах или тексте

Устаревшая ставка, неверный срок или битая ссылка — открой issue по шаблону
«Ошибка в данных» и приложи источник (zus.pl, podatki.gov.pl, Dziennik Ustaw).
Тексты гайда правятся в [sobolevbel/jdg](https://github.com/sobolevbel/jdg):
приложение берёт их оттуда при сборке.

## Код

1. Ветка от свежего `main`, один PR — одна тема. В `main` напрямую не пушим.
2. Тесты до PR:
   ```bash
   NO_NET=1 pytest -q --ignore=test_webapp_browser.py
   NO_NET=1 pytest -q test_webapp_browser.py
   ```
   CI гоняет обе части; красный CI — не мёржим.
3. В описании PR (шаблон подставится сам): причина, что было багом, тесты, что не вошло.
4. Переводы строк — LF. На Windows с `core.autocrlf=true` проверь `git diff --check`.

## Правила проекта

- **Ставки — только в `rates_years.json`.** Калькуляторы, дашборд и ассистент читают
  их оттуда; вторую копию цифр не заводить. Неизвестное — `null`, прогноз — в `forecast`.
- **`calc.py` и `webapp/calc.js` — зеркала.** Меняешь одно — меняй другое; браузерный
  тест сверяет их по каждому году.
- **Никакого inline JS** в HTML: код страницы — в `webapp/js/<страница>.js` (CSP, `test_csp.py`).
- **Движок PKD не назначает главный код и не придумывает коды.** Исключение кандидата —
  только официальное «nie obejmuje» или подтверждённый факт; новые правила — со сценарием
  в `tests/fixtures/pkd/`.
- **Модель ИИ одна** — `monitor.MODEL`. Всё, что идёт в запрос, — из своих данных
  или белого списка; ворота до модели должны отсекать посторонние запросы бесплатно.
- **Секреты** — только в `.env`, его нет в git. Список переменных — `.env.example`.
